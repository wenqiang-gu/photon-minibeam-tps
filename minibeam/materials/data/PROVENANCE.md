# Reference material table

commit `2d6f0cb3884a91561b8e35b783b8ba5911e982e9`,
`examples/Patient/HUtoMaterialSchneider.txt`.

Source: https://github.com/OpenTOPAS/OpenTOPAS/blob/v4.2.3/examples/Patient/HUtoMaterialSchneider.txt

The accompanying OpenTOPAS MIT license is in `OpenTOPAS-LICENSE.txt`.
This reference table is an example, not a scanner-specific calibration.
Original CT DICOM files are copied unchanged; TOPAS performs native DICOM rescaling.
The stock Schneider converter clamps values below -1000 or above 2995 HU.
Supply `material_file` to substitute your conversion table for `Ge/Patient`.
